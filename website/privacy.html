Privacy

This page covers the browser extension DeltaSync — KeePass search & go, in every browser it is published for: Firefox, Microsoft Edge and Chrome. The short version is that it collects nothing, and sends nothing anywhere.

What the extension can read

The extension cannot open a KeePass database itself. It asks the keepass-deltasync program on your own computer, which opens your .kdbx file and hands back, for each entry:

  • its title
  • its web addresses
  • the name of the group it is in
  • an internal identifier, so the popup can tell two entries with the same title apart

That list is fixed in the program, not in the extension, so a fault in the extension cannot widen it. Passwords, usernames, notes and attachments are never handed over.

The extension asks for no access to websites and runs no code in the pages you visit. It cannot see what you browse.

Your master password

If you have stored the master password in your operating system's keyring, the program takes it from there, and it never passes through the browser at all.

If you have not, the popup asks for it and passes it straight to the program on your computer. The extension does not store it. The program keeps it in memory only, and wipes it when it has been idle for a while, when you press Lock, or when the browser closes.

Where it is kept

The list above is kept in the browser's session storage while the browser is open, so that a search does not have to open the database on every keystroke. Session storage lives in memory and is gone when the browser closes. Lock clears it at once. The extension writes nothing to disk.

What it sends

Nothing. The extension's only connection is to the keepass-deltasync program on the same computer, through the browser's native messaging. It makes no network requests, contains no analytics or tracking, and has no server to report to. Searching works without an internet connection and without a DeltaSync account.

Opening an entry's website is an ordinary visit to that website, exactly as if you had typed the address yourself.

Nothing is sold or shared

No data is collected, so there is none to sell, share or use for any other purpose.

This website

deltasync.org sets no cookies and loads no scripts, fonts or other resources from third parties. Like any web server, the host may keep ordinary access logs.

Checking this yourself

The extension and the program are open source under the GPL-3.0, and the published packages are reproducible from the source. The design and its security boundaries are described in docs/browser-extension.md.

Contact

Questions about privacy go to the project's issue tracker. For anything you would rather not raise in public, see SECURITY.md.
