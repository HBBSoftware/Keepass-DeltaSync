Kom i gang

Denne side dækker både hvordan du kommer i gang som bruger (din administrator har inviteret dig) og hvordan du deployer en server selv.

Som bruger

Du skal bruge:

  • En enrollment-token fra din administrator
  • KeePassXC installeret (desktop-klienten bruger dens keepassxc-cli til at læse og merge .kdbx-filer)
  • En præ-bygget binær til Linux, macOS eller Windows — eller Go 1.26+ hvis du hellere vil bygge den selv

På en telefon skal du ikke bruge noget af ovenstående — installér bare Android-app'en (se På Android nedenfor).

Skrivebordsprogrammet, hvis du helst vil undgå terminalen

Alt herunder kan gøres i et vindue i stedet. Skrivebordsprogrammet er en tynd skal om den samme kommandolinje-klient — det ejer hverken kryptering, server-logik eller sin egen konfiguration, det kører blot klienten for dig og viser resultatet. Hvad du gør det ene sted, kan du se det andet.

På Windows henter du KeePass-Delta-Sync-Setup-<version>.exe fra releases-siden. Den installerer begge programmer i samme mappe, hvilket er dét der lader programmet finde klienten uden nogen PATH-opsætning, og den installerer kun for din egen bruger — ingen administrator-prompt. På Linux tager du .tar.xz-filen fra samme side; på macOS bygger du den med make package-darwin, da en signeret .app kræver en Mac at bygge på.

Første gang du starter det, spørger en guide om server-adresse og din enrollment-token, dernæst om navn og fil til din .kdbx — de samme to trin som enroll og init nedenfor. Derefter får du et dashboard med faneblade til Databaser, Enheder, Aktivitet, Log, Administration og Indstillinger, så du kan synkronisere én database eller dem alle, følge med i hvad klienten laver, og skifte sproget mellem dansk og engelsk.

Under Indstillinger ligger også autostart, som beder styresystemet køre keepass-deltasync daemon når du logger ind — en "ved logon"-opgave i Opgaveplanlægning på Windows, launchd på macOS, systemd --user på Linux. Det sættes op helt inde i dit eget brugerområde, så det kræver heller ingen administrator, og baggrunds-synkroniseringen kører derefter uanset om programmet er åbent.

Trin

  1. Byg klienten 
    git clone https://gitlab.com/Star95/keepass-deltasync.git
cd keepass-deltasync/client
go build -o keepass-deltasync ./cmd/keepass-deltasync
    Læg keepass-deltasync i din PATH eller kør den direkte med ./keepass-deltasync.
  2. Enroll din enhed med engangs-token fra admin: 
    ./keepass-deltasync enroll --server https://deltasync.example.com <din-token>
    Klienten genererer et X25519-keypair lokalt og sender public-delen til serveren. Private-delen forbliver på din enhed.
  3. Bind en lokal .kdbx-fil: 
    ./keepass-deltasync init mypasswords ~/keepass/my.kdbx
    Eller hvis du allerede har samme database synket på en anden enhed: 
    ./keepass-deltasync databases   # se UUID på den eksisterende
./keepass-deltasync init mypasswords ~/keepass/my.kdbx --bind <UUID>
  4. Synkronisér: 
    ./keepass-deltasync sync mypasswords
    Du skal indtaste dit masterpassword. Klienten kører Argon2id lokalt (~200 ms) og synker.
  5. Lad daemon køre i baggrunden for automatisk sync: 
    ./keepass-deltasync daemon --store-keyring
    Første gang prompter den for password og gemmer det i OS-keyring (Windows Credential Manager / macOS Keychain / libsecret). Næste gang starter daemon helt non-interaktivt.

Kør daemon automatisk ved login

Når daemon'en virker, når du selv starter den, kan du få din computer til at starte den for dig ved hvert login, så sync "bare sker". Kør den manuelle --store-keyring-kommando først (trin 5 ovenfor) og indtast dit master-password én gang — autostart afhænger af at passwordet allerede er gemt i OS-keyringen, for der er ingen til at taste det ved opstart.

Windows

Den enkleste, pålidelige måde er en lille launcher der starter daemon'en skjult (intet sort konsol-vindue), lagt i din Startup-mappe.

  1. Ved siden af keepass-deltasync.exe: opret en tekstfil med navnet start-daemon-hidden.vbs med dette indhold (ret mappestien til hvor din .exe faktisk ligger): 
    Set sh = CreateObject("WScript.Shell")
sh.CurrentDirectory = "C:\Tools\keepass-deltasync"
sh.Run "keepass-deltasync.exe daemon", 0, False
    0 betyder "kør skjult".
  2. Tryk Windows+R, skriv shell:startup, og tryk Enter. Windows åbner din personlige Startup-mappe.
  3. Højreklik start-daemon-hidden.vbs → Kopiér, og højreklik så inde i Startup-mappen → Indsæt genvej. Det var det — daemon'en starter nu skjult hver gang du logger ind.

Valgfrit — Opgavestyring (Task Scheduler) (mere robust: den kan genstarte daemon'en hvis den skulle crashe). Åbn Opgavestyring → Opret opgave…, tilføj en udløser "Ved logon", og en handling "Start et program" med program wscript.exe og argument den fulde sti til din .vbs-fil. Vælg "Kør kun når brugeren er logget på" — det er nødvendigt for at opgaven kan læse dit password fra Windows Credential Manager. Det samme som en one-liner i PowerShell:

schtasks /create /tn "KeePass DeltaSync" /sc onlogon /rl limited /f /tr "wscript.exe \"C:\Tools\keepass-deltasync\start-daemon-hidden.vbs\""

Linux

Brug en systemd user-service. Opret filen ~/.config/systemd/user/keepass-deltasync.service:

[Unit]
Description=KeePass DeltaSync daemon
After=graphical-session.target

[Service]
ExecStart=%h/.local/bin/keepass-deltasync daemon
Restart=on-failure

[Install]
WantedBy=default.target

Ret ExecStart-stien til hvor du har lagt programmet. Aktivér og start den så:

systemctl --user daemon-reload
systemctl --user enable --now keepass-deltasync.service
systemctl --user status keepass-deltasync.service   # bekræft at den kører

Se dens log-output når som helst med:

journalctl --user -u keepass-deltasync -f
Keyring-note (Linux): daemon'en læser dit gemte password fra desktop-secret-tjenesten (GNOME Keyring / KWallet, via libsecret), som låses op når du logger ind på dit grafiske skrivebord — så servicen starter rent i en almindelig desktop-session. På en headless server uden en oplåst keyring vil keyring-opslaget fejle; der skal du i stedet køre daemon'en med --password-stdin der læser fra en beskyttet fil. Vil du have servicen til at blive ved med at køre efter du logger ud, så slå lingering til: loginctl enable-linger $USER.

På Android

Android-app'en er en sync-tjeneste: den har ingen indbygget entry-editor. Den holder din .kdbx-fil synkroniseret i baggrunden, og du læser og redigerer dine passwords i din sædvanlige Android-KeePass-app — Keepass2Android eller KeePassDX, som begge åbner den samme fil.

  1. Installér app'en. Den hurtigste vej i dag er Obtainium, som henter den signerede APK direkte fra GitHub Releases og holder den opdateret. Peg den på det repository, filtrér release-titler med ^DeltaSync Android og træk versionen ud med [0-9.]+$ — samme repository udgiver også desktop-releases, og de to filtre holder dem adskilt. F-Droid optog app'en i deres katalog 10. september 2026, så den kanal er på vej; byggene er reproducerbare og bærer samme signatur, så du kan skifte mellem de to uden at afinstallere.
  2. Enroll enheden på hovedskærmen. Tryk Scan QR-kode og hold kameraet op mod koden i admin-panelet, eller indtast server-URL og engangs-enrollment-token i hånden. App'en genererer et X25519-keypair og gemmer device-token i Android Keystore. En server over almindelig HTTP virker også, hvis den kun svarer på dit eget netværk.
  3. Vælg din .kdbx via systemets fil-vælger og match den til databasen på serveren. Har serveren ingen database endnu, opretter app'en selv en — du behøver ikke længere desktop-klienten for at få den første på plads.
  4. Synk nu — indtast dit masterpassword for at synke én gang. Vil du holde den synket automatisk, så slå “Auto-synk i baggrunden” til på hovedskærmen: du bekræfter én gang med biometri (eller din enheds-PIN), og passwordet gemmes krypteret i Android Keystore (aldrig i klartekst). Derefter synker app'en af sig selv — uden password, uden fingeraftryk — med det interval du vælger (15, 30 eller 60 minutter). Tomme tjek er billige: den laver kun den fulde dekryptér-og-merge når filen eller serveren faktisk har ændret sig.
  5. Del fra app'en hvis du er ejer: del-skærmen lister medlemmer, tilføjer ét via brugernavn, og fjerner adgang igen — samme flow som desktop'ens share-kommando.

Sletninger lavet i Keepass2Android / KeePassDX (papirkurv eller permanent) propagerer til serveren og til dine andre enheder, præcis som på desktop.

Modtag en delt database

Hvis nogen deler en database med dig, dukker den op i din liste:

./keepass-deltasync databases
# NAME          ID                                    ...  role=member

Bootstrap en lokal kopi med init-shared:

./keepass-deltasync init-shared shared-vault ~/keepass/shared.kdbx

Du vælger et nyt lokalt password til din kopi — det behøver ikke at være det samme som ejerens. Bagefter kan du synke, edit'e og dele tilbage som ethvert andet vault.

Del en database med en anden bruger

# Del 'mypasswords' med bruger 'alice'
./keepass-deltasync share mypasswords alice

# Liste medlemmer
./keepass-deltasync shares mypasswords

# Fjern medlemskab
./keepass-deltasync unshare mypasswords alice
Trust-model: når du deler en database, får modtageren fuld read-write-adgang til alle entries. Sharing er asymmetrisk krypteret men ikke "revokable" i kryptografisk forstand — se arkitektur for detaljer.

I Firefox — søg og gå

Firefox-udvidelsen besvarer ét spørgsmål: hvilken side lå den konto nu på? Skriv kp i adresselinjen efterfulgt af en søgning, eller tryk Alt+Shift+K for en popup, så fører den dig til entryens hjemmeside. Selve login er stadig KeePassXC-Browsers arbejde — denne her bringer dig blot hen på siden, så den kan gøre sit, og derfor har den aldrig brug for at se et password. Den modtager titler, adresser og gruppenavne, og beder ikke om adgang til nogen websider.

Den kræver ikke en DeltaSync-server: en søgning rører aldrig netværket, for hjælperen læser din lokale .kdbx gennem keepassxc-cli og svarer ud fra den alene. Vil du kun have søgningen og er ligeglad med synkronisering, kan du køre klienten rent lokalt.

Installér Firefox-udvidelsen gennemgår begge veje — med din eksisterende DeltaSync-opsætning, eller alene uden server — samt registrering af native messaging-hosten og hvad du gør, når der ikke sker noget.

Som administrator

Du vil typisk være ansvarlig for at deploye serveren og oprette bruger-konti. Den fulde deployment-guide ligger i repoet:

  • docs/deployment.md — tre konkrete deployment-recipes
  • docs/threat-model.md — hvad serveren ser, ikke ser, og hvad trust-modellen er
  • server/README.md — server-overblik

Hurtigste deployment-flow

  1. Upload server/-koden til din webhost (Hetzner shared hosting eller similar PHP+PostgreSQL).
  2. Opret PostgreSQL-databasen og kør migrationerne fra server/schema/ (sekventielt 001 til 007).
  3. Udfyld server/.env baseret på .env.example (DB-credentials, log-niveau).
  4. Generér første admin-token via en SQL-snippet: 
    ./keepass-deltasync admin token-sql
# kopiér output til DBeaver, kør, gem 'admin_token' fra resultatet
  5. Opret brugere via admin-CLI: 
    $env:KEEPASS_DELTASYNC_ADMIN_TOKEN = "<token>"   # PowerShell
./keepass-deltasync admin user-create alice --display-name "Alice Smith"
# Returnerer enrollment-token til Alice
  6. Send enrollment-token til brugeren via en sikker kanal (ikke email). De bruger den én gang i enroll-kommandoen og får derefter en permanent device-token gemt i deres lokale config.

Daglig drift

Admin-kommandoer:

./keepass-deltasync admin user-list                 # tabular oversigt
./keepass-deltasync admin user-enrollment alice     # ny enroll-token til ekstra enhed
./keepass-deltasync admin user-disable alice        # blokér login uden at slette data
./keepass-deltasync admin user-enable alice
./keepass-deltasync admin user-delete alice --yes   # permanent, CASCADE

Audit-log er tilgængelig via:

./keepass-deltasync log                             # din egen aktivitet
# admin /api/v1/admin/log endpoint giver hele log'en

Fejlfinding

"keepassxc-cli not found"

Klienten leder efter keepassxc-cli i PATH, eller på Windows i C:\Program Files\KeePassXC\. Hvis den ligger andet sted, sæt env-var:

$env:KEEPASSXC_CLI = "C:\path\to\keepassxc-cli.exe"
# eller pass --keepassxc-cli FLAG til hver kommando

"empty password on stdin"

Du har piped noget tomt til --password-stdin. Brug interaktiv prompt i stedet (drop flag'et) eller verificér at din pipe leverer noget. På Windows er echo "pw" | klient ... tricky — brug PowerShell-syntax: "pw" | klient ....

"server URL not configured"

Du har ikke kørt enroll endnu, eller din config.toml er væk. Find filen:

  • Windows: %APPDATA%\keepass-deltasync\config.toml
  • macOS: ~/Library/Application Support/keepass-deltasync/config.toml
  • Linux: ~/.config/keepass-deltasync/config.toml

Daemon spammer "Fetching..." i logs

Skulle ikke ske — daemon kører quiet-mode. Hvis det sker, du har formentlig en gammel binær — rebuild fra HEAD.
