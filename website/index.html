End-to-end encrypted KeePass sync

Sync your KeePass databases across devices without giving the server access to your passwords. Argon2id + XChaCha20-Poly1305 + KeePassXC's native merge.

Get started See the architecture

Why DeltaSync

Almost every existing KeePass sync solution has the same weakness: either the server sees your entries in cleartext, or you have to dump the entire .kdbx file somewhere and hope the conflict-merge sorts itself out. DeltaSync syncs at the entry level and uses KeePassXC's own merge engine on the client, so concurrent edits from multiple devices merge without loss.

🔒

Real end-to-end

Your master password never leaves your device. The server only sees opaque encrypted blobs — it cannot reveal titles, usernames, or passwords even if compromised.

⚡

Incremental sync

Only changed entries are sent. Versioned history (3 levels) per entry — undo accidents with restore.

👥

Multi-user sharing

Share a database with another user via X25519 sealed-box wrapping. The recipient gets their own encrypted copy that they control.

📁

KeePassXC-compatible

Uses KeePassXC's existing .kdbx files and merge logic. No new file formats, no extra installs beyond a small client.

🖥️

A window, not a terminal

A desktop app for Windows, Linux and macOS walks you through enrollment, then shows your databases, devices and activity. On Windows one installer puts it and the command-line client in the same folder — no PATH to set and no administrator needed.

🦊

Find it in Firefox

Type kp in the address bar to search your entries by site, title or group and land on the right page. The extension only ever receives titles and URLs — filling in credentials stays with KeePassXC-Browser. How to install it.

🧩

Also in Edge and Chrome

The same extension, built from the same source files. It is on Microsoft's add-on store for Edge; in Chrome it installs from source until it reaches the Web Store. How to install it.

📱

Desktop & Android

A cross-platform desktop client (Linux, macOS, Windows) plus an Android app. Both share the same Go crypto core, so they produce byte-identical encrypted blobs on the wire.

How it works

  1. Enroll once per device with a one-time token from your administrator. Each device generates its own keypair locally.
  2. Bind a local .kdbx to the server with init. The file format is exactly the same as before — you can still open it in KeePassXC.
  3. Let it sync in the background — on desktop the daemon reacts to your edits within seconds (fsnotify) plus periodic polling; on Android, WorkManager runs periodic sync, with your master password held in the Android Keystore behind a biometric opt-in.
  4. Share databases with other users when you need to — from the desktop client or the Android app. Sharing is asymmetrically encrypted: only the recipient's device can unwrap the master_key.

On Android, DeltaSync is a sync service — it keeps the .kdbx file up to date in the background, while you read and edit entries in your favourite Android KeePass app (Keepass2Android or KeePassDX).

None of this needs a terminal. The desktop app does the same four steps in a window: it opens a wizard the first time, asks for the server address and your token, lets you pick your .kdbx, and can switch on background sync at login for you.

Quick start

If you already have an account and an enrollment token:

On Windows, take the installer from the releases page. It places the desktop app and the command-line client in the same folder and installs for your user only, so it never asks for administrator rights. Start KeePass Delta-Sync and the wizard takes it from there.

On Linux and macOS, take a pre-built client binary from the same page — or build it yourself:

# Build the client
git clone https://gitlab.com/Star95/keepass-deltasync.git
cd keepass-deltasync/client
go build -o keepass-deltasync ./cmd/keepass-deltasync

# Enroll
./keepass-deltasync enroll --server https://deltasync.org <your-token>

# Register your .kdbx
./keepass-deltasync init mypasswords ~/keepass/my.kdbx

# Sync
./keepass-deltasync sync mypasswords

For more detailed instructions — including the daemon, the Android app, sharing, and the admin flow — see the getting started page.

Status: the server, the desktop client (with pre-built binaries for Linux, macOS and Windows), the desktop app and multi-user sharing are all in production on deltasync.org. The Android app is feature-complete — background sync, biometric-protected password storage and database sharing all work. It is on F-Droid, and also installs through Obtainium from GitHub Releases. The Firefox extension is published on addons.mozilla.org, signed and installable like any other add-on.
